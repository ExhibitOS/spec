# T01-01 — Artwork contract evidence

Implemented: OES Artwork1.0.0-draft.1 schema, model/image examples, semantic and
optional local binary CLI, version compatibility ADR and independent usage docs.
No exhibition/OEX/OED, generated types or stable contract release claimed.

Prerequisite: accepted synthetic baseline; assets unchanged. Environment:
macOS arm64, Node24.21.0/npm11.19.0. Exact Ajv8.20.0, ajv-formats3.0.1 and
Khronos validator2.0.0-dev.3.10 are locked. Official JSON Schema, Ajv and glTF
references were checked on 2026-10-01.

Checks: `npm ci --ignore-scripts`, `npm run check`, both `validate:artwork` example
commands, clean standalone export install/check and `git diff --check`.
Result: 34 tests passed including existing four baseline tests. Both artwork
examples passed document, hash/size/GLB-or-image-signature and publication checks.
Khronos baseline validation retained zero errors/warnings.

Acceptance: no private Capture fields or repo dependency; explicit meter/Yup/XYZW,
positive dimensions/scale, exact manifest and rights/provenance; unsupported
versions, missing rights/license, malformed hash, wrong scale, corrupt asset,
non-unit quaternion, bad UUID/calendar, reference errors and unsafe paths/symlinks
rejected. Validators do not mutate input. Publication-time display/expiry checks
are separate from retaining private expired/unavailable-rights artifacts.

Limits: rights ownership is a producer claim, not legal title verification. Image
content is not fully decoded. Production isolation, TOCTOU-resistant staging and
permissions belong to platform ingestion, not this local validator. Schema version
is draft; no prior stable migration exists. Platform consumers are a later task.
Recovery: prior synthetic baseline and source commits; no user artwork touched.

Review fix: RFC3339 leap-second acceptance by the format plugin could produce
Date.parse NaN and bypass expiry comparison. The draft now rejects leap seconds
and sub-millisecond timestamp precision, checks finite parsing, and covers rights
start/expiry at exact millisecond boundaries. Added two regression tests pass.
